# Project 05 - Baltimore City Homicide Data Analysis

## Statistic Chosen: Victim Age Distribution

I chose age distribution because it reveals which age groups
are most affected by homicide in Baltimore, telling a meaningful
story about community impact.

## How to Run
./run.sh

## Data Source
https://chamspage.blogspot.com/2025/01/2025-baltimore-city-homicide-list.html

## Assumptions
- Data scraped from HTML tables on the blog
- Non-numeric and missing ages are excluded
- Ages outside 0-120 treated as data errors
